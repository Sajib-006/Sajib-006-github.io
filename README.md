# Personal Portfolio Starter

This repository now contains a complete static portfolio starter website:

- `index.html` - main page structure and content
- `style.css` - all styling (responsive + dark theme)
- `script.js` - mobile menu + auto-updating footer year

## Quick start

1. Open `index.html`
2. Replace every placeholder value:
   - `YOUR_NAME`
   - `YOUR_CITY, YOUR_COUNTRY`
   - `your.email@example.com`
   - `YOUR_USERNAME`
   - `YOUR_LINKEDIN`
   - sample project names/descriptions/links
3. Commit and push your edits
4. Enable GitHub Pages in repository settings (if not already enabled)

## Where to edit your profile details

### Hero section
- Update your name, role, intro text, location, and email.

### About section
- Replace with a short paragraph about who you are and what you do.

### Skills section
- Add/remove skills to match your real stack.

### Projects section
- Replace all project cards with your real projects:
  - project title
  - short description
  - tech stack
  - GitHub code URL
  - live demo URL (if available)

### Contact section
- Update email, GitHub URL, and LinkedIn URL.

## Important note about GitHub Pages

For a personal root site URL like:

`https://YOUR_USERNAME.github.io`

the repository name should be:

`YOUR_USERNAME.github.io`

If your repository name is different, it can still host a project page, but
the URL path will include the repository name.
